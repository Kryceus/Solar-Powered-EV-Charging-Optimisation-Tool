# Solar-Powered-EV-Charging-Optimisation-Tool

A Python tool that estimates the cheapest times to charge an electric vehicle using:

- Solar radiation forecasts from Open-Meteo
- Household energy consumption
- EV charging demand
- Time-of-use electricity pricing

The tool generates hourly charging cost estimates, identifies the most cost-effective charging periods, and visualises charging costs throughout the day.

## Technologies

- Python
- Pandas
- Requests
- Matplotlib
- Open-Meteo API

## Example Output

- Hourly charging cost recommendations
- Best and worst charging times
- Daily charging cost visualisation

## Disclaimer

Solar generation is estimated using forecast radiation data and simplified system efficiency assumptions. Results are intended for educational and analytical purposes.
